# clash-profile
自用Clash配置文件yaml

1.实现多机场节点链接自动更新：

  打开yaml文件，将proxy-providers中的url替换成自己的机场clash订阅节点即可使用，默认每24小时自动更新节点信息。

2.代理规则部分引用第三方规则集（24小时自动更新），规则集部分来自站内@blackmatrix7。

3.若机场不提供clash订阅链接，可使用Sub-store或第三方站点（如https://suburl.v1.mk  ）转换为clash链接（注意，第三方转换链接可能导致订阅信息泄露，请自行甄别）。

4.安卓推荐客户端Flclash，Windows推荐客户端Clash verge。
